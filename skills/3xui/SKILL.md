# 3x-ui 安装与配置

交付能使用的面板、用户要求的节点和订阅，以及可接手的中文维护文档。默认目录 `~/app/3xui`，用户指定位置时遵循用户选择。本 skill 可独立使用；同时有 `install-app` 时可沿用其通用目录与文档约定。

## 先识别任务和现状

- 读取目标目录及父目录适用的 `AGENTS.md`，再读现有 README、当前状态、需求、运维步骤。已有数据库不重新初始化；本次仅要求写 skill 或排查时，不据此变更运行服务。
- 区分首次安装、节点/客户端变更、订阅与分流、升级、故障排查。沿用会话已确定的要求，只询问真正缺失的信息。
- 确认目标客户端及实际内核版本、需要的协议、是否要求公网管理、域名/TLS、IPv4/IPv6 和是否要 UDP。客户端外壳版本不能代替 Mihomo/Xray 内核版本。
- 历史部署中的端口、城市名、SNI、版本、握手开关、无限流量和客户端数量都不是新机器的默认需求。不要复制旧机器的 UUID、密钥、订阅 ID 或运行数据。

## 安装和升级

读取 [部署与维护](references/deployment.md)。以官方项目 `MHSanaei/3x-ui` 为来源，安装时核实稳定发布、镜像架构、Xray 及运行时兼容性，固定应用版本，适用时固定镜像 digest；不能把参考中的历史版本当作当前最新版。

Compose 适用时优先使用桥接网络和明确的端口映射；host 网络、Fail2ban、NET_ADMIN 或反向代理按实际需要选择，不为方便统一开启。运行环境受限时区分沙箱与宿主机，不反复尝试被策略禁止的操作。

首次启动先限制管理入口到本机，通过 SSH 隧道设置随机强凭据和管理路径。用户已要求公网管理时据此配置，核对监听、TLS、主机防火墙及云安全组；HTTP 不能被报告为加密入口。面板端口来自实际配置，不根据原生安装脚本或旧部署猜测。

## 配置节点和客户端

- 按用户选择创建或复用入站。新增设备通常为现有入站增加独立客户端，使用独立 UUID，明确关联入站，并按需求设置流量和到期时间。
- VLESS + REALITY + Vision 按实际 Xray 版本核实传输方式、flow、目标/SNI、密钥、公钥、shortId 和客户端支持。验证目标从服务端可达及适用的 TLS 能力，不固定使用历史 SNI。
- REALITY 节点不必依赖自有域名证书，但面板和订阅的 HTTPS 是另外两项配置；不要混为一谈。
- 入站下拉框为空时检查入站是否启用、列表 API 和页面缓存，不把不关联入站当成解决方案。
- 名称修改区分入站备注、客户端备注、客户端本机订阅名称、订阅 ID；只改用户指向的字段。只想改订阅显示名称时不要轮换作为访问令牌的订阅 ID。
- 凭据与敏感导出保存在受限文件，聊天和文档只写读取位置。客户端导出不包含服务端私钥；日志、API 响应和订阅内容先过滤再输出。

## 订阅、分流和兼容性

读取 [客户端与订阅](references/clients.md)，按客户端逐项完成配置。不要以手工生成静态文件代替用户要求的动态订阅。

- 分别检查 SUB、CLASH、UA 自动识别的实际开关和订阅端口。面板能登录不代表订阅服务已发布。
- 拉取真实订阅并检查格式和参数，不能只看 HTTP 200；验证配置能被目标内核解析及实际建立代理连接。
- 国内/局域网直连等需求属于客户端分流。区分面板保存的运行设置、规则维护副本、静态导出和用户设备的实际生效配置。
- `unsupported format type: mrs` 优先按规则格式兼容性排查；REALITY 握手失败按服务端与客户端内核和实际参数排查，不盲目改变全机网络配置。
- 订阅 ID 轮换后验证新旧地址并更新客户端订阅来源；旧地址失效不等于缓存节点失效，不把轮换订阅令牌等同于撤销节点访问。

## 验证和交接

执行适用的 `docker compose config --quiet`、脚本语法检查和 Xray/Mihomo 配置检查。真实验证管理员登录、用户要求的订阅格式、客户端实际代理请求；有分流需求时用日志或控制器证明直连/代理的规则命中，不能只看请求成功。

分开记录服务器本机访问、服务器上的客户端测试、独立外网入站测试和用户设备实测。服务器上的代理请求成功不能证明手机线路、云安全组、iOS 兼容或 UDP 已验证。清理验证启动的临时客户端、控制器和监听。

交付 `AGENTS.md`、README 和 `docs/current-state.md`、`docs/requirements.md`、`docs/operations.md`、`docs/deployment-log.md`。当前状态记录精确版本、配置来源、监听与映射、功能状态、备份入口、验证范围和待办；历史日志只追加。结束时说明完成范围、凭据私下读取位置和未验证项，不公开敏感访问地址。
